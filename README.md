# 🎙️Arok - AI 기반 자동 회의록 시스템

<img width="1376" height="768" alt="meeting_scene_1" src="https://github.com/user-attachments/assets/1a240e0e-adbc-46e6-be60-020d334d9147" />


Arok은 회의 음성을 자동으로 분석하고 요약해주는 AI 기반 웹 서비스이에요.

## ⭐ 주요 기능

- **실시간 녹음** - 마이크로 회의를 바로 녹음
- **파일 업로드** - 기존 오디오 파일(MP3, WAV, M4A, OGG) 업로드
- **STT 변환** - 음성을 텍스트로 자동 변환, 화자 구분
- **AI 요약** - 주요 내용 / 결정 사항 / 후속 조치 / 키워드 자동 정리
- **회의록 관리** - 날짜·키워드 검색, 목록 관리
- **인사이트** - 회의 통계 대시보드 (빈도, 화자 발언 비율, 키워드)



## 🛠️ 기술 스택

- **Frontend**: React + TypeScript + Vite + Tailwind CSS
- **UI/UX Design**: Figma



## 💻 화면 구성

| 화면           | 설명                                       |
| -------------- | ------------------------------------------ |
| New Meeting    | 회의 제목 입력 → 방식 선택 (실시간/업로드) |
| Live Recording | 실시간 녹음 및 STT 변환                    |
| Audio Upload   | 오디오 파일 업로드 및 분석                 |
| Meeting List   | 회의록 목록 조회 및 관리                   |
| Meeting Detail | 대화 내용 + AI 요약 결과                   |
| Insight        | 회의 통계 대시보드                         |
